# Competitor audit, October 2026

Four learning sites compared with Groundwork: GreatFrontEnd (GFE), LeetCode (LC), NeetCode (NC) and freeCodeCamp (fCC). Public pages only: no login, no account, no paywall bypass, nothing copied. Every observation was made on 2026-10-17 from a logged-out browser. Groundwork facts were re-checked in this repo at commit `19a024d` (main).

**Labels.** _observed_ means I saw it on the page or in the source. _inferred_ means I concluded it from something observed, and the row says from what. _unknown_ means the browser cannot show it. **How.** PT is visible page text read in a browser tab; DOM is button and tab labels read from the page; NET is an REA browser capture of network requests; REPO is source I read; TERMS is a terms page. Marketing text proves a claim is made, not that the feature works; those rows say so.

## 5. Five features Groundwork lacks that learners would value most

Ranked by how many of the four sites ship the feature. That is a count, not a learner survey, so the ranking is _inferred_.

1. **Progress that follows you between devices.** Shown by all four sites (G1, L9, N7, F1), always behind an account. Groundwork has no export or import (a search of `app`, `components` and `lib` for export, import-progress and backup found nothing). A downloadable progress file would fit its no-server design.
2. **Comments or discussion on a question.** GFE (G11), LC (L8), fCC (F9). Needs a backend and moderation, which Groundwork does not have.
3. **Named-company question lists.** GFE (G8), LC (L6), NC (N3, N7). Groundwork lists companies per round only. Tagging each question is content work, and the question text itself must stay original.
4. **AI help on a problem.** LC (L5), NC (N6). Groundwork's content standard asks for three written hints per exercise, and the code makes no model calls, so this would be its first server cost.
5. **Contests or head-to-head races.** LC (L7), NC (N5). Needs accounts and a server.

Certificates (G10, F3) tie at two sites, but Groundwork says its checks are a self-check, not a certificate, so I left them out.

## 6. What I could not verify

- Whether anything judged or ranked server-side works as advertised: judging, contest rating, Versus matching, "Lightning Judge", Ask Leet, NeetBot, AI hints (G12, L10, N10). Rows built on pricing pages are marketing claims only.
- Features behind a login or paywall. I did not log in, so progress pages, streaks, saved code and premium content were not seen. "Not seen" in section 4 is not "absent".
- Whether GFE's "Save" and "Mark complete" work signed out, and whether LC's "Run" does (not clicked).
- fCC's licence for lesson text. The terms name none, and I did not read its contributing documents.
- NeetCode's counts (N2): the two figures conflict.
- Prices: GFE and LC show country-adjusted prices, so I recorded none.
- Whether a feature is valued. Section 5 counts sites.

**Departures from the brief.** REA was used once (N8). GFE and LC forbid scraping and reverse engineering, and fCC forbids non-browser programs, so on those three sites I read pages in a browser tab, using short scripts to read visible text and labels. Even that is automated reading and may not fit GFE's clause 1.3(e), so you may want to stop at the DOM rows. Before reading the terms I also fetched each terms page once with a plain HTTP tool: GFE returned 404 and LC 403 (nothing retrieved), and the fCC fetch, a program that is not a web browser, succeeded once.
